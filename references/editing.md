# 浏览器编辑与 PowerPoint 导出

已确认的内容和设计流程不变。全稿完成后，用 `scripts/enable_editor.py <现有稿目录> <新的可编辑输出目录>` 生成新的交付版本；保留原稿。打包脚本需要 Python 3.10+ 和 beautifulsoup4，浏览器运行不需要安装依赖。

## 交付结构与操作

输出的 index.html 内嵌样式、照片、播放器、编辑器和导出库，双击即可离线播放。底部“编辑 / 导出”进入编辑，直接点字输入、点照片换图和调裁切；支持撤销、重做。编辑时显示当前页全部分拍文字，暂停动画并隔离输入快捷键；退出后恢复分拍播放。长文本提示可能超界，不自动缩小或删字。

草稿存储在当前浏览器，不等于保存到项目。用户可选择文件写入或下载新 HTML。可选运行同目录 serve_editor.py 开启本机服务，自动回写 index.html，使用文件哈希防止旧窗口覆盖，首次保存留备份。服务只监听 127.0.0.1，校验同源、随机令牌和字段。修改记录可下载交给 AI。

## AI 接续手改稿

- 先读最新 HTML 的 deck-edit-config 与 deck-edit-state。按照固定 data-edit-id / data-edit-media 应用状态；旧 outline.md 仅代表此前确认，不能覆盖用户手改。
- deckId 标识项目，baseVersion 标识生成基线，revision 标识编辑状态。不可根据当前页面顺序重新编号旧 ID。增页增字段须分配新 ID，并明确迁移基线；不能静默忽略旧草稿。
- 不对已有可编辑稿重复执行 enable_editor.py；脚本会拒绝。修改其设计时保留 ID、用户状态和原始图片基线，另存新版本并重新验证。
- 不直接拿运行后的 DOM 保存：它含工具面板、目录按钮和临时播放状态。使用编辑器序列化接口，避免再打开时出现重复控件。

## PPTX 的实际范围

独立适配器使用 MIT 许可的 PptxGenJS 4.0.1 和 html2canvas 1.4.1，未使用 Dashi 的代码或专有引擎。版本、来源和哈希见 templates/vendor/provenance.json；分发须保留 vendor 许可与生成的 THIRD-PARTY-NOTICES.txt。

导出的文件是真正的 Open XML .pptx。按浏览器实际换行、位置、字号、字距和颜色建立原生文本框；照片、渐变、SVG 装饰合成每页一张背景图。文字可在 PowerPoint 中编辑，背景中的照片和装饰不能逐对象编辑，HTML 动画不转换。HTML 可替换照片后重新导出。换电脑缺字体可能发生差异，不承诺像素级一致。

当前底座为 1600×900，导出为等比例 16×9 英寸。仅标记的普通文字转成原生文本；SVG 内文字、图表标签和 CSS 生成内容仍可能在背景内。复杂 CSS、滤镜和视频须单独验证，不能将现有六页验证推广为所有 HTML 都兼容。

## 验证

至少检验：中文输入不翻页、撤销重做、被蒙层覆盖的照片选择、换图裁切、清空浏览器上下文后打开保存文件、离线资源、退出编辑后分拍恢复、PPTX 原生文字与实际内容一致。使用本地服务时增加真实落盘、备份及两个窗口冲突检查。

源码语法通过不代表编辑可用；PPTX ZIP/XML 通过不代表已在 PowerPoint/WPS 实际渲染。报告实际验证环境与未覆盖项。
