# 质量检查

检查与修复按风险选择，不为了轮次重复跑。页面结构改变后至少检查所有新增/受影响页；底座改变后运行播放回归。

1. 内容：与来源核对；不遗漏用户重点；数字、比率、结论一致；无占位文字；模拟标识清楚；不把建议写成效果证明。
2. 设计：实际打开所有最终页面，复杂动画还要查看中间状态；标题能读，表格有单位，无溢出/遮挡，连线不穿字，页间构图有变化且风格一致。
3. 播放：第一页到最后一页逐拍前进/回退；跳页、URL 定位、备注、自动播放与暂停、全屏、缩放、减少动态效果。重新打开后内容可用。
4. 交付：断网打开、资源无丢失、无本机绝对路径或运行时 CDN；来源和字体说明随包；源数据可回查。

`python scripts/check_deck.py <deck>` 只做静态校验，不证明视觉正确。

`python scripts/verify_browser.py <deck> --browser <chrome-path>` 会离线打开成品、遍历状态、验证前进回退、检查页面边界与文本容器溢出、测试控制和缩放，并在 `qa/` 写报告/截图。默认使用 Playwright 自带 Chromium，可传本机浏览器路径。每次完整执行写入独立时间戳目录，不覆盖旧证据。

自动几何检查不能判断审美、语义或全部元素重叠；必须实际查看截图。缺少浏览器依赖时人工检查并标记自动检查未运行。自动扫描的通过不能升级成跨平台验证或模型效果验证。
